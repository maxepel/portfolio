# Orbit Sun image

`orbit-sun-nasa.jpg` is an unmodified 150 × 150 JPEG rendition of NASA photo PIA26681, “Image of Sun From NASA’s Solar Dynamics Observatory,” observed September 10, 2025. Credit: NASA/GSFC/Solar Dynamics Observatory.

Source page: https://science.nasa.gov/photojournal/image-of-sun-from-nasas-solar-dynamics-observatory/

Downloaded rendition: https://assets.science.nasa.gov/dynamicimage/assets/science/psd/photojournal/pia/pia26/pia26681/PIA26681.jpg?crop=faces%2Cfocalpoint&fit=crop&h=150&w=150

The SVG in `panel.js` clips inside the solar limb at display time to remove the surrounding black background. The bundled file is unchanged and needs no network request at runtime. This is an illustrative, colorized solar observation rather than a live image.
